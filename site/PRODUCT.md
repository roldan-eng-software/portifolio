# Product: "Jack" 3D Creator Portfolio

## Description
A high-end, immersive 3D Creator portfolio landing page for "Jack". The design focuses on "Experience" mode—the interface recedes, allowing the 3D artifacts and animations to lead. The aesthetic is dark, premium, and futuristic.

## Core Features
- **Hero Section:** Full-screen layout with a magnetic 3D portrait, massive animated gradient heading, and clear navigation.
- **Marquee Section:** Auto-scrolling grid of 21 project GIFs.
- **About Section:** "About me" section with floating 3D decorative assets and scroll-triggered character animations.
- **Services Section:** Clean, professional service breakdown with staggered fade-in animations.
- **Projects Section:** Sticky-stacking project cards with scale-down effects on scroll.

## Design System
- **Theme:** Dark (#0C0C0C background).
- **Typography:** 'Kanit' (Google Fonts, weights 300-900).
- **Highlights:** Gradient text `.hero-heading` (#646973 to #BBCCD7).
- **Interactions:** Scroll-driven animations (Framer Motion), Magnetic hover effects, Sticky stacking cards.

## Technical Stack
- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Motion:** Framer Motion
- **Icons:** Lucide React
