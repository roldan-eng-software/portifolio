# Portfolio Website

A modern portfolio website built with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), and [Framer Motion](https://www.framer.com/motion/).

## Prerequisites

- [Node.js](https://nodejs.org/) (v18.19+ recommended)
- npm or yarn

## Getting Started

Follow these steps to run the site locally:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Open the site**:
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Design Maintenance**: Impeccable (via `npx impeccable`)

## Development Notes

- This project includes the **Impeccable** design tool. You can use it to audit and maintain visual consistency.
- If you make changes to the design and want to check for consistency, you can run:
  ```bash
  npx impeccable detect
  ```
